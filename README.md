# Fashion_Mnist
Do PCA on Fashion-Mnist data set and the do 5 fold cross validation with SVM, Bayes, KNN, MLP on this data set and compared the results

## Code guide

`main.py` implements custom and scikit-learn PCA paths and compares SVM, Naive Bayes, k-nearest neighbors, and MLP classifiers. `HW2.ipynb` is a short accompanying notebook, while the PNG files are saved comparison figures. The script imports pandas, NumPy, Matplotlib, and scikit-learn. Review its data-loading paths before running `python main.py` from the repository root; the committed plots are historical outputs.
